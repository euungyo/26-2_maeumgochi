# 하드웨어

이 디렉터리에는 회로도, 핀 배치, 배선 자료와 부품 데이터시트를 저장합니다.

## 관리 규칙

- 핀 번호를 변경하면 펌웨어 설정과 배선 문서를 함께 수정합니다.
- 각 센서의 전압, 통신 방식, I2C 주소를 기록합니다.
- 데이터시트 원본이 크면 파일 대신 공식 링크와 버전을 문서로 남깁니다.
- 회로 변경에는 변경 이유와 시험 결과를 함께 기록합니다.
- 배터리를 연결하기 전에 커넥터 규격과 극성을 확인합니다.

## 예정 장치

- Seeed Studio XIAO ESP32-S3 Plus
- ST7789 240×240 LCD
- BMI270 IMU
- LTR390 UV 센서
- PCF8523 RTC
- L76K GNSS
- 물리 버튼
- 진동모터 및 MOSFET 구동회로
- 3.7 V Li-Po 배터리

BMI270과 PCF8523의 기본 I2C 주소가 겹칠 수 있으므로 실제 조립 전에 주소 설정을 확인합니다.
